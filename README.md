To run locally:

On Windows:
1. Open Windows Powershell
2. Navigate to the project folder `cd C:\Users\asmac\src\ClassLink`
3. ` python app.py`
4. Open the link in the browser that is shown on the last line


On Mac:
1. Open Mac Terminal
2. Navigate to the project folder
3. `python3 app.py`
4. Open the link in the browser that is shown on the last file
